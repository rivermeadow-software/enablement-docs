# Introduction
---
This course provides a technical deep dive on the RiverMeadow platform's integration with Amazon Web Services (AWS). You will learn how to migrate, optimize, and modernize workloads from any source to Amazon EC2.

### Audience

This course is intended for anyone looking to migrate workloads from on-premises hypervisors, physical servers, or other public clouds to AWS.

### Prerequisites

The following prerequisites should be met by learners:

* A basic understanding of Amazon Web Services (AWS) and Amazon EC2.
* A basic understanding of the RiverMeadow platform.

### Learning Objectives

By the end of this course, you will be able to:

* Explain the RiverMeadow solution architecture, deployment methods, and solution components.
* Explain the supported migration methods and the use cases where each method should be used.
* Describe the network ports and protocols and the AWS services required by the RiverMeadow solution.
* Describe how to deploy and configure the RiverMeadow solution components to enable server migrations to AWS.
* Explain how source servers are discovered and added to the RiverMeadow inventory, including the RVTools, AWS Transform, and Cloudamize integrations.
* Explain the migration process and the steps involved in migrating a server to Amazon EC2.
* Describe how workloads are optimized and modernized during the migration to AWS.
