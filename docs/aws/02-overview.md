# Solution Overview
---
The RiverMeadow platform is a workload mobility solution that enables organizations to migrate, optimize, and modernize workloads (physical servers, virtual machines, and cloud instances) from any source to over a dozen target clouds and hypervisors.

* **Workload Mobility:** Migrate workloads across hybrid and multi-cloud environments.
* **Workload Optimization:** Optimize workloads to improve security and reduce operational costs.
* **Workload Modernization:** Modernize workloads to reduce technical debt and accelerate innovation.

## AWS Ecosystem Mobility

The RiverMeadow platform migrates workloads from public and private clouds to the AWS ecosystem, optimizing and modernizing them along the way. The following AWS ecosystem targets are supported by the RiverMeadow platform. This course focuses on migrations to Amazon EC2.

| Target | Description |
|:------:|:-----------:|
| **Amazon EC2** | Migrate servers to Amazon EC2 instances backed by EBS volumes. |
| **AWS Outposts** | Migrate servers to EC2 instances running on AWS Outposts in an on-premises location. |
| **Amazon Elastic VMware Service (EVS)** | Migrate virtual machines to VMware Cloud Foundation running in Amazon EVS. |
| **Red Hat OpenShift Service on AWS (ROSA)** | Migrate virtual machines to OpenShift Virtualization running on ROSA. |
| **Nutanix Cloud Clusters (NC2)** | Migrate virtual machines to Nutanix clusters running on AWS bare metal instances. |

## Common Use Cases
The RiverMeadow platform enables the migration of physical servers, virtual machines, and cloud instances to AWS. The following table details the common platform use cases related to the integration with AWS.

| Use Case | Description |
| --- | --- |
| **VMware to AWS Migration** | Migrate VMs running on VMware vSphere (including VMware on AWS and Azure VMware Solution) to Amazon EC2. |
| **Microsoft Hyper-V to AWS Migration** | Migrate VMs running on Microsoft Hyper-V to Amazon EC2. |
| **Nutanix AHV to AWS Migration** | Migrate VMs running on Nutanix AHV to Amazon EC2. |
| **KVM, OpenStack, and RHEV to AWS Migration** | Migrate VMs running on KVM-based platforms such as OpenStack and Red Hat Enterprise Virtualization (RHEV) to Amazon EC2. |
| **Physical Server to AWS Migration** | Migrate bare metal servers running Windows or Linux to Amazon EC2. |
| **Public Cloud to AWS Migration** | Migrate instances running on public clouds such as Microsoft Azure, Google Cloud (GCP), Alibaba Cloud, and Huawei Cloud to Amazon EC2. |
| **AWS to AWS Migration** | Migrate EC2 instances between AWS accounts or regions. |

## Platform Features

The following platform features can be used during migrations to AWS:

| Feature | Description |
|:-------:|:-----------:|
| **Workload Migration** | Migrate physical servers, virtual machines, and cloud instances from any source to any supported target. |
| **Preflight Migration Checks** | 200+ intelligent preflight migration checks executed during different pre-migration phases. |
| **Migration Extensions** | Automate post-migration tasks using custom automation with Bash and PowerShell scripts. |
| **Storage Rightsizing** | Right size disks or storage volumes during the workload migration. |
| **Operating System Hardening** | Harden Windows and Linux operating systems to CIS Benchmark standards during the workload migration. |
| **OS Modernization** | Automated Windows and Linux operating system upgrades during the workload migration. |
| **SQL Modernization** | Automated Microsoft SQL Server upgrades during the workload migration. |
| **Linux OS Conversion** | Automated conversion between Linux OS distributions during the workload migration. |
