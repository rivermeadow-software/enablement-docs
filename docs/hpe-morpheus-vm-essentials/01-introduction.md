# Introduction
---
This course provides a technical deep dive on the RiverMeadow platform's integration with HPE Morpheus VM Essentials. You will learn how to migrate workloads from any source to the HVM hypervisor available in HPE Morpheus VM Essentials.

### Audience

This course is intended for anyone looking to migrate workloads from on-premises hypervisors or public clouds to HPE Morpheus VM Esssentials.

### Prerequisites

The following prerequisites should be met by learners:

* A basic understanding of HPE Morpheus VM Esssentials
* A basic understanding of the RiverMeadow platform

### Learning Objectives

By the end of this course, you will be able to:

* Explain the RiverMeadow solution architecture and the solution components.
* Describe how to deploy and configure the RiverMeadow solution components to enable server migrations to the HVM hypervisor available in HPE Morpheus VM Essentials.
* Describe the network ports and protocols required for the RiverMeadow solution.
* Explain the supported migration methods and the use cases where each method should used.
* Explain the migration process and the various steps that are involved in migrating a server to the HVM hypervisor.
