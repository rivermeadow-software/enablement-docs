# Solution Overview (DONE)
---
The RiverMeadow platform is a workload mobility solution that enables organizations to migrate, optimize, and modernize workloads (physical servers and virtual machines) from any source to over a dozen target clouds and hypervisors.

## Use Cases
The RiverMeadow platform enables the migration of physical servers, virtual machines and cloud instance to HPE Morpheus VM Esssentials. The following list details the common platform use cases related to the integration with HPE Morpheus VM Essentials.

* **VMware to HPE Morpheus VM Essentials Migration:** Migrate VMs running on VMware vSphere to an HVM cluster managed with HPE Morpheus VM Essentials.
* **Microsoft Hyper-V to HPE Morpheus VM Essentials Migration:** Migrate VMs running on Microsoft Hyper-V to an HVM cluster managed with HPE Morpheus VM Essentials.
* **Nutanix AHV to HPE Morpheus VM Essentials Migration:** Migrate VMs running on Nutanix AHV to an HVM cluster managed with HPE Morpheus VM Essentials.
* **Proxmox to HPE Morpheus VM Essentials Migration:** Migrate VMs running on Proxmox to an HVM cluster managed with HPE Morpheus VM Essentials.
* **RHEV to HPE Morpheus VM Essentials Migration:** Migrate VMs running on Red Hat Enterprise Virtualization (RHEV) to an HVM cluster managed with HPE Morpheus VM Essentials.
* **Physical Server to HPE Morpheus VM Essentials Migration:** Migrate physical servers running Windows or Linux to an HVM cluster managed with HPE Morpheus VM Essentials.
* **Public Cloud to HPE Morpheus VM Essentials Migration:** Migrate instances or virtual machines running on public clouds such as AWS, Azure, GCP, and more to an HVM cluster managed with HPE Morpheus VM Essentials.
