# Solution Overview
---
The RiverMeadow platform is a workload mobility solution that enables organizations to migrate, optimize, and modernize workloads (physical servers and virtual machines) from any source to over a dozen target clouds and hypervisors.

## Common Use Cases
The RiverMeadow platform enables the migration of physical servers, virtual machines and cloud instance to Microsoft Hyper-V. The following list details the common platform use cases related to the integration with Microsoft Hyper-V.

* **VMware to Microsoft Hyper-V Migration:** Migrate VMs running on VMware vSphere to Microsoft Hyper-V.
* **Nutanix AHV to Microsoft Hyper-V Migration:** Migrate VMs running on Nutanix AHV to an Microsoft Hyper-V.
* **Proxmox to Microsoft Hyper-V Migration:** Migrate VMs running on Proxmox to Microsoft Hyper-V.
* **RHEV to Microsoft Hyper-V Migration:** Migrate VMs running on Red Hat Enterprise Virtualization (RHEV) to Microsoft Hyper-V.
* **Physical Server to Microsoft Hyper-V Migration:** Migrate physical servers running Windows or Linux to Microsoft Hyper-V.
* **Public Cloud to Microsoft Hyper-V Migration:** Migrate instances or virtual machines running on public clouds such as AWS, Azure, GCP, and more to Microsoft Hyper-V.
