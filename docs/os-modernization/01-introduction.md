# Introduction
---
This course provides a technical overview of the RiverMeadow platform's operating system modernization capability.

### Audience

This course is intended for anyone looking to automate the upgrade systems running Windows Server or Linux operating systems.

### Prerequisites

The following prerequisites should be met by learners:

* A basic understanding of the RiverMeadow platform.

### Learning Objectives

After completing this course, you’ll be able to:

* Explain the RiverMeadow solution architecture and the solution components.
* Compare performing operating system upgrade manually versus automated via the RiverMeadow platform.
* Describe the modernization workflow for Windows and Linux operating system upgrades.
