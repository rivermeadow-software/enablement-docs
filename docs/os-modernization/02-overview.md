# Overview
---

The RiverMeadow platform enables the automated upgrade of Linux and Windows operating systems to go from older versions to newer versions. The process is done in a derisked fashion as the platform creates an exact copy of the source system and performs the automated upgrade of the operating system on the clone.

## Snapshot based

The common practice is to take a snapshot of the virtual machine being upgraded prior to the upgrade process to enable a quick rollback to a working state.
