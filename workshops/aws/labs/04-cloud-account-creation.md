# Lab #2 - RiverMeadow Cloud Account

In this exercise you’ll walk through setting up the AWS cloud account integration in the RiverMeadow platform.

**Lab Steps**

1. Access the RiverMeadow platform by clicking on the link in the email you received from noreply@rivermeadow and
set a password. If you have already registered and created a password then use your existing password to log into
https://migrate.rivermeadow.com.
2. Click **Manage** from the left navigation menu to expand the manage section.
3. Click **Migration Appliances** under the **Manage** section on the left navigation menu.
4. Click the **Add New Migration Appliance** button from the top menu bar.
5. Select **AWS** from the **Cloud Type** select list.
6. Provide a name for the cloud account using the following naming convention: rm-student## (i.e. student02 =
rm-student02)
7. Enter the AWS ARN of the IAM Role that you created in the previous lab exercise in the **Role** text box.
8. Click the **Test Connection** button to validate that the IAM role is properly configured.
9. Uncheck the **Setup Migration Appliance for this target cloud** checkbox to create the cloud account without
immediately deploying the migration appliance.
10. Click the **Add Migration Appliance** button to create the cloud account.
