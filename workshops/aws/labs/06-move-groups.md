# Lab #4 - Move Groups

In this exercise you’ll walk through creating a move group to organize and group source workloads for migration.
Steps

**Lab Steps**

1. Click on the **Manage** menu from the left navigation menu of the RiverMeadow platform to expand the manage
section.
2. Click **Move Groups** from the **Manage** left navigation menu.
3. Click the **Add Application or Move Group** button from the top menu bar.
4. Enter a name for the move group in the **Application or Move Group Name** text box using the following naming
convention: rm-student## (i.e. student02 = rm-student02)
5. Click the **Add Application or Move Group** button to create the move group.
